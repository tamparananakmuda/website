## Hashtag Strategy

| Platform | Jumlah | Format |
|----------|--------|--------|
| Instagram | 8-15 | 3-5 niche + 3-5 brand + 2-5 broad |
| X/Twitter | 1-3 | 1-2 niche + 1 brand |
| LinkedIn | 3-5 | 2-3 niche + 1-2 industry |
| TikTok | 3-5 | 2-3 trending + 1-2 niche |

Hashtag TAM default: `#tamparananakmuda #tamparananakmuda #genzindonesia`

Niche hashtags per kategori:
- Mindset: `#mindsetgrowth #mentalhealthindonesia #selfimprovement`
- Karier: `#kariergenz #freelanceindonesia #tipskarier`
- Uang: `#finansialgenz #investasiindonesia #literasikeuangan`
- Bisnis: `#bisnisanakmuda #startupindonesia #sidehustle`
- Kehidupan: `#kehidupangenz #quarterlifecrisis #dewasamuda`
- Teknologi: `#teknologigenz #aiindonesia #produktivitas`

## Cross-Posting Strategy

| From → To | Adaptasi |
|-----------|----------|
| IG Carousel → X/Twitter | Pecah jadi thread, 1 slide = 1 tweet |
| IG Carousel → LinkedIn | Tulis ulang jadi post text-first, attach 3-4 slide terbaik |
| Newsletter → IG Carousel | Pecah 1 insight jadi 5-8 slides |
| X/Twitter thread → LinkedIn | Gabung jadi 1 post paragraf, tambah CTA |
| Artikel → TikTok | 1 insight = 1 video 30-60 detik |

## Template Copy Per Platform

### Instagram Carousel (5-8 slides per part)

```
[Slide 1 - Hook]
[OG headline atau hook provokatif]
[Visual: category color background]

[Slide 2-6 - Data points]
[1 data point per slide, besar dan jelas]
[Source di bawah]

[Slide 7 - Pertanyaan refleksi]
"Pernah ngerasain hal ini?"

[Slide 8 - CTA]
"Baca full artikel di bio"
Link: tamparananakmuda.com/artikel/SLUG
```

### Seri Overview Carousel (10-12 slides, publish setelah seri selesai)

```
[Slide 1 - Hook seri]
"[Hook seri overview]"
"SERI [NAMA SERI] - [N] parts"

[Slide 2 - Kenapa seri ini]
[1 paragraf kenapa topik ini penting]

[Slide 3-N - 1 slide per part]
"Part [N]: [Judul part]"
[1 insight utama dari part tersebut]
[Link ke part]

[Slide N+1 - CTA binge read]
"Baca semua part di bio"
Link: tamparananakmuda.com/artikel/SERI-SLUG-PART-1
```

### X/Twitter Thread (3-5 tweets per part)

```
Tweet 1 (Hook):
[Hook 1 kalimat, provokatif]
Thread ini bahas [topik]. 🧵

Tweet 2-4 (Insights):
[1 insight per tweet + data]

Tweet 5 (CTA):
Baca full artikel: tamparananakmuda.com/artikel/SLUG
```

### LinkedIn Post (200-400 words per part)

```
[Hook professional, 1-2 kalimat]

[Konteks: kenapa topik ini penting untuk profesional muda]

[1 insight utama + data]

[CTA: "Baca full artikel di link komentar"]

#tamparananakmuda #[niche hashtag] #[industry hashtag]
```

### Newsletter (400-600 words per part)

```
Subject: [1 insight utama, bukan judul]

Body:
[Hai nama reader],

[1 paragraf hook]

[2-3 paragraf insight utama dari part ini]

[CTA: "Baca full artikel di sini: tamparananakmuda.com/artikel/SLUG"]

[Signature TAM]
```

## Binge-Read CTA (seri-specific)

Setelah seri selesai (semua part published), tambahkan CTA binge-read di setiap part:

```markdown
Baca seri [Nama Seri] dari awal:
- Part 1: [link]
- Part 2: [link]
- Part 3: [link]
```

Dan promote seri overview carousel di IG dengan CTA: "Binge read semua part di bio"
