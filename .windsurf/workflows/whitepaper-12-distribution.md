## Cross-Posting Strategy

| From ke To | Adaptasi |
|------------|----------|
| IG Carousel ke X/Twitter | Pecah jadi thread, 1 slide = 1 tweet |
| IG Carousel ke LinkedIn | Tulis ulang jadi Article, attach 3-4 slide terbaik |
| Newsletter ke IG Carousel | Pecah 1 insight jadi 5-8 slides |
| Whitepaper ke Infographic | 1-page summary untuk IG/Twitter/LinkedIn |
| Whitepaper ke Webinar | Pecah jadi 30-45 min presentation + Q&A |

## Template Copy Per Platform

### Instagram Carousel (8-12 slides)

```
[Slide 1 - Hook]
[Data paling striking + title whitepaper]
[Visual: OLED black + category color]

[Slide 2-10 - Key data points]
[1 data point per slide, max 3 angka per slide]
[Source di bawah]

[Slide 11 - Pertanyaan refleksi]
"Apa ini yang terjadi di tempat kerjamu?"

[Slide 12 - CTA]
"Baca full whitepaper di bio"
Link: tamparananakmuda.com/whitepaper/SLUG
```

### X/Twitter Thread (5-8 tweets)

```
Tweet 1 (Hook):
[Data paling striking, 1 kalimat]
Thread ini bahas [topik]. 

Tweet 2-6 (Insights):
[1 insight per tweet + data + source]

Tweet 7 (Quote/data striking):
[Data yang paling memukau]

Tweet 8 (CTA):
Baca full whitepaper: tamparananakmuda.com/whitepaper/SLUG
```

### LinkedIn Article (400-600 words)

```
[Hook professional, 1-2 kalimat]

[Konteks: kenapa topik ini penting untuk profesional muda]

[2-3 insight dengan sudut pandang professional + data]

[CTA: "Baca analisis lengkapnya di sini: tamparananakmuda.com/whitepaper/SLUG"]

#tamparananakmuda #[industry hashtag] #[niche hashtag]
```

Publish sebagai LinkedIn Article (bukan post biasa) untuk reach lebih luas.

### Newsletter (600-800 words)

```
Subject: [1 insight utama, bukan judul whitepaper]

Body:
[Hai nama reader],

[1 paragraf hook: data paling striking]

[2-3 paragraf insight utama dari whitepaper]

[1 quote striking dari whitepaper]

[1 pertanyaan untuk subscriber]

[CTA: "Baca full whitepaper di sini: tamparananakmuda.com/whitepaper/SLUG"]

[Signature TAM]
```

Kirim via: Brevo dashboard (manual).

## PR Pitch Template (whitepaper-specific)

Whitepaper lebih sering dipitch ke media daripada artikel. Kirim pitch ke 3-5 jurnalis:

```
Subject: Riset baru TAM: [1 insight utama yang menarik untuk media]

Hai [Nama Jurnalis],

Saya dari TAMPARAN ANAK MUDA, media yang fokus pada realita generasi muda Indonesia.

Kami baru saja rilis whitepaper: "[Judul Whitepaper]".

Beberapa temuan yang mungkin menarik untuk [media/outlet]:

1. [Data 1 yang striking]
2. [Data 2 yang striking]
3. [Data 3 yang striking]

Whitepaper ini berdasarkan data dari [sumber utama: BPS, OJK, dll.].

Kalau tertarik untuk liputan, saya bisa kirim:
- Full whitepaper (PDF)
- Infographic summary
- Data tambahan untuk visualisasi
- Wawancara dengan tim riset

Link whitepaper: tamparananakmuda.com/whitepaper/SLUG

Terima kasih,
[Tim TAM]
```

Target media: Katadata, Kompas, Detik, Tech in Asia, DailySocial.

## Lead Generation Strategy (whitepaper-specific)

Whitepaper ideal untuk lead gen:

| Taktik | Cara |
|--------|------|
| **Email gate** | Newsletter signup untuk akses PDF download |
| **PDF download** | Set `downloadUrl`, track download count di 13-monitor |
| **Webinar registration** | Email capture untuk webinar |
| **LinkedIn lead gen** | LinkedIn Article dengan CTA ke whitepaper page |
| **Follow-up sequence** | 3 email follow-up setelah download (H+1, H+3, H+7) |
