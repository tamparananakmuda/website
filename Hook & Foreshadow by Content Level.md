# Hook & Foreshadow by Content Level

> **Fokus**: Cara pakai formula Hook & Foreshadow untuk 3 level konten — **Artikel**, **Seri**, dan **Whitepaper**. Hanya judul, subjudul, thumbnail, meta title, meta description, dan bridge/tease. Tidak menyentuh isi body konten.

## 3 Level Konten

| Level | Format | Fokus Hook & Foreshadow |
|---|---|---|
| **Artikel** | 1 artikel tunggal | 1 Hook (judul) + 1 Foreshadow (subjudul) |
| **Seri** | 3-10 episode | Series Hook + Series Foreshadow + Hook/Foreshadow per episode + Next Tease |
| **Whitepaper** | Dokumen mendalam | Executive Hook + Executive Foreshadow + Hook/Foreshadow per section + Bridge |

**Prinsip umum:**
- Hook = menarik perhatian, mematahkan asumsi, membuat penasaran
- Foreshadow = janjikan insight, buka open loop, buat reader lanjut
- Body = isi konten (tidak dibahas di file ini)

## Level 1: Artikel

### Struktur Hook & Foreshadow

```
Judul (H1)          → Hook (max 70 karakter)
Subjudul (H2)       → Foreshadow (max 170 karakter)
Thumbnail text      → Hook (max 5 kata / 40 karakter)
Thumbnail caption   → Foreshadow (max 20-30 kata / 160 karakter)
Meta title          → Variasi Hook (max 60 karakter)
Meta description    → Hook + Foreshadow + CTA lembut (max 155-160 karakter)
```

### Aturan

- **1 formula Hook** untuk judul
- **1 formula Foreshadow** untuk subjudul
- Thumbnail text adalah versi pendek dari Hook
- Thumbnail caption adalah versi pendek dari Foreshadow
- Meta title dan meta description untuk SEO, tetap berdasarkan Hook & Foreshadow

### Formula Hook untuk Artikel

#### Formula 01 — Expectation vs Reality
```
[X] Bukan [Y]: Kenapa [asumsi umum] Adalah Mitos
```
```
Banyak Orang Mengira [X]. Faktanya [Y].
```
```
[X] Tidak Seperti yang Kamu Kira
```

#### Formula 07 — Myth Breaking
```
Kalau Kamu Masih Percaya [X], Saatnya Berpikir Ulang
```
```
Mitos Terbesar tentang [X] yang Harus Kamu Tinggalkan
```
```
[X] Adalah Mitos. Ini Kenyataannya.
```

#### Formula 10 — False Belief
```
Kesalahan Terbesar tentang [X] yang Dilakukan Hampir Semua Orang
```
```
Kesalahan Terbesar yang Dilakukan Banyak Orang: [X]
```
```
Jangan Lakukan [X] Kalau Kamu Mau [Y]
```

#### Formula 19 — Reframe
```
Masalahmu Bukan [X]. Masalahmu Adalah [Y].
```
```
Bukan [X] yang Salah. Tapi [Y] yang Belum Kamu Pahami.
```
```
Kamu Pikir Masalahnya [X]. Sebenarnya [Y].
```

#### Formula 22 — Hidden Truth
```
Yang Tidak Pernah Diajarkan tentang [X]
```
```
Yang Tidak Pernah Dibahas tentang [X]: [Y]
```
```
[X] yang Tidak Kamu Pelajari di Sekolah
```

### Formula Foreshadow untuk Artikel

#### Formula 01 — Promise
```
Di akhir artikel ini, kamu akan paham [X].
```

#### Formula 02 — Curiosity
```
Masalahnya bukan [X]. Ada [Y] yang tidak kamu sadari.
```

#### Formula 06 — Transformation
```
Setelah memahami ini, cara kamu melihat [X] akan berubah.
```

#### Formula 18 — Personal
```
Aku dulu juga berpikir seperti itu. Sampai [X].
```

### Formula Thumbnail Text (versi pendek Hook)

| Formula | Template (max 5 kata) |
|---|---|
| 01 | `[X] ≠ [Y]` / `[X] Bukan [Y]` |
| 07 | `[X] = Mitos` / `Stop Percaya [X]` |
| 10 | `Kesalahan Terbesar: [X]` |
| 19 | `Bukan [X]. Tapi [Y].` |
| 22 | `Yang Tidak Diajarkan...` |

### Formula Meta Description

```
Banyak orang mengira [X]. Padahal [Y]. Di artikel ini, kamu akan memahami [Z] — dan kenapa [insight] lebih penting dari yang kamu kira.
```

### Contoh Lengkap

**Topik: Kerja Keras**

- **Judul (Hook 01 — Expectation vs Reality):** `Kerja Keras Bukan Jawabannya. Ini Yang Sebenarnya Membuatmu Kaya.`
- **Subjudul (Foreshadow 02 — Curiosity):** `Masalahnya bukan seberapa keras kamu kerja. Ada satu konsep yang membedakan orang yang kerja keras dari orang yang bangun kekayaan.`
- **Thumbnail text:** `Kerja Keras ≠ Kaya`
- **Thumbnail caption:** `Banyak orang bekerja keras seumur hidup tapi tetap tidak kaya. Ada satu konsep yang membedakan.`
- **Meta title:** `Kerja Keras Bukan Jawabannya: Apa yang Sebenarnya Membuatmu Kaya`
- **Meta description:** `Banyak orang mengira kerja keras adalah jalan menuju kekayaan. Padahal masalahnya lebih dalam. Pelajari satu konsep yang membedakan orang yang kerja keras dari orang yang bangun kekayaan.`

## Level 2: Konten Ber-seri

### Struktur Hook & Foreshadow

```
Series Landing Page
  ├─ Series Title        → Series Hook (max 60 karakter)
  ├─ Series Subtitle     → Series Foreshadow (max 160 karakter)
  └─ Series Teaser       → Why this series matters (2-3 kalimat)

Per Episode
  ├─ Episode Title       → Episode Hook (max 70 karakter)
  ├─ Episode Subtitle    → Episode Foreshadow (max 170 karakter)
  ├─ Opening Tease       → Recap dari episode sebelumnya (opsional, max 100 karakter)
  ├─ Next Tease          → Foreshadow ke episode berikutnya (max 120 karakter)
  └─ Thumbnail text      → Episode Hook (max 5 kata)
```

### Aturan

- **Series Hook** harus menjual seluruh seri, bukan 1 episode
- **Series Foreshadow** janjikan payoff akhir seri
- **Episode Hook** boleh pakai formula berbeda dari Series Hook
- **Next Tease** wajib ada, kecuali episode terakhir
- Episode terakhir pakai **Final Payoff Tease** ke CTA (download, whitepaper, dll)

## Level 3: Whitepaper

### Struktur Hook & Foreshadow

```
Cover Page
  ├─ Whitepaper Title    → Executive Hook (max 80 karakter)
  └─ Whitepaper Subtitle → Executive Foreshadow (max 200 karakter)

Executive Summary
  ├─ Problem Hook        → Hook masalah utama (2-3 kalimat)
  └─ Promise Foreshadow  → Janji framework/insight (2-3 kalimat)

Per Section
  ├─ Section Title (H2)  → Section Hook (max 70 karakter)
  ├─ Section Lead        → Section Foreshadow (max 150-200 karakter)
  └─ Bridge              → Foreshadow ke section berikutnya (1-2 kalimat)
```

### Aturan

- **Executive Hook** di cover harus menjual seluruh whitepaper
- **Executive Foreshadow** janjikan framework atau insight unik
- Setiap section punya **Section Hook + Section Foreshadow** sendiri
- Bridge wajib ada di akhir section, kecuali section terakhir
- Whitepaper boleh lebih panjang, lebih formal, tapi tetap conversational

**Section 3:**
- **Section Title (Hook 14 — Prediction):** `Framework 90 Hari: Cara Praktis Memulai dari Nol Tanpa Modal Besar`
- **Section Lead (Foreshadow 13 — Reveal Promise):** `Framework ini bukan teori. Ini langkah-langkah konkret yang bisa langsung kamu jalankan.`
